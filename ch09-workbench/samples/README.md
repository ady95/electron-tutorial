# 실습용 샘플 문서

9장 실습에 쓰는 문서입니다. 회사와 내용은 모두 가상입니다.

| 파일 | 확인할 점 |
|---|---|
| `회의록-신제품-출시.txt` | UTF-8 텍스트. 요약·핵심어·질문 응답 실습용 |
| `공지-연말-휴무-cp949.txt` | CP949(메모장의 옛 ANSI)로 저장한 텍스트. 인코딩 자동 판별 확인용 |
| `제품-소개서.pdf` | 글자가 들어 있는 PDF 3쪽 (표 포함) |
| `스캔-거래명세서.pdf` | 글자 없이 그림으로만 된 PDF. "글자를 찾지 못함" 경고 확인용 |

PDF 두 개는 Electron의 `webContents.printToPDF()`로 만들었습니다.
